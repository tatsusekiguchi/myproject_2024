ABOUT FUBUTURE WORKS

いつだって、「今」になじむ。

株式会社FILEのオリジナル家具ブランド「 FILE FURNITURE WORKS 」。「FILE FURNITURE WORKS」の家具たちは、FILE京都店からも近い自然豊かな靜原にある山間の自社工房にて、 熟練の家具職人の手により、美しい造形と手触りの良い質感、そのモノのもつ空気感を大切に、お使い頂く方のために日々新しい命を宿しています。
ひとつひとつをアートワークと捉えた製作のプロセスにおいては、「スケッチ」→「 ミニチュア模型」→「モックアップ」

と各工程を経て、 丁寧な仕事の中で造形として洗練された後に完成します。
時代が変わっても決して世間の潮流に左右されず確固たる価値観を持つ、そんな家具を日々作り続けております。
1点もののオーダーにも対応していますので、お気軽にご相談ください。

BRAND FEATURES

創業30年の匠の技を生かしたものづくり

株式会社FILEは京都にて創業より30年を迎えました。
熟練の職人により作り出される家具には、長年の経験・知識が織り込まれております。
例えば家具に用いる材木も１つ１つその家具に最適なものを採用しております。
国産の山桜、ナラ、檜はもとより、国外の材木からも厳選しております。
すべては最高の1品を創り出すため。
私たちはこれまでも、これからもこの姿勢を変えることなく今日も家具を生み出してまいります。

自然豊かな靜原の地で「ものづくり」に生きる

FILE FURNITURE WORKSの家具は全て自社工房にて一つひとつ手作りで作られております。
私たちの工房は京都店からも近い静原の静かな山間にあります。
昔より続く自然の息遣いを日々感じながら家具づくりに向き合う日常は、「ものづくり」に生きる職人にとって何よりの空間となります。

この工房で生み出される１つ１つの家具は時代を、そして世代を超えて使い続けていただけると信じ、作り続けてまいります。
