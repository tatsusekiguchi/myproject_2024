ABOUT KITCHEN

FILE のキッチンは全てカスタムメイドで製作しており、ライフスタイルに合った設備機器、家具やインテリアに合ったデザイン、それぞれのモノに最適な収納を提案します。

多くの人は日々の食生活の充実が幸せに繋がっているのではないかと思っています。
理想のキッチンとは、シンプルで機能的なものであったり、デザインを追求したものであったりと人によって様々ですが、キッチンは家族の健康を守る大切な場所であり、私たちにとっては幸せのもととなる特別な場所です。
FILE のキッチンは楽しくお料理をできること、片付けやお掃除が気持ちよくできること、そして食事の満足度が上がることも大切に考えています。
特に料理をする際の動線はとても大切なポイントです。

長年の経験を生かしたヒアリングと提案で最適な空間を創り上げてまいります。
お客様のライフスタイルに沿った最適なキッチンをすべて自社工場にてカスタムメイドでお作りいたします。
