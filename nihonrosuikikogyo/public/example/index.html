USAGE EXAMPLE

使用例

①菌を取り除きたい（目的：除菌）

納入先：酵素、バイオ、食品、飲料、水産試験場、水族館

〈フロー例〉

セラポアは高い濾過精度を有しており、除菌目的での使用例が多いです。
メンブレンと比較してブラッシング機能による経済効果が大きく、酵素製造工程(除菌工程)にて高いシェアを誇っています。
酵素の他にも、バイオ、食品、飲料、海水等の除菌濾過でも多数ご使用頂いています。
＊ブラッシング機能：目詰まりが発生した際に、フィルター表面をブラッシングし、目詰まり箇所を取り除く機能

②濁りを取りたい（目的：除濁、清澄化）

納入先：香料、化粧品、飲料、ワイン、化学

〈フロー例〉

濁りを取り除き、清澄化させる目的で濾過機を使用することが多いです。
香料メーカーなどでは、濾紙と濾過助剤を組み合わせることで、液中の濁度成分を取り除いています。
濁り成分の粒子の大きさによっては、濾紙では除濁ができない場合もあります。
セラポアの場合は、濾紙よりも濾過精度が高いことから、濾過助剤を使用せず、ワンパスで除濁できるケースが多いです。
求める清澄度合いによって、セラポアの濾過精度を選択することができます。

〈実例紹介〉

③異物・不純物を取りたい

納入先：ベアリング、RO の前処理、化学

〈フロー例〉

ベアリング加工時の洗浄油濾過では、プレコート濾過機が使用されています。
高い清浄度を実現できる為、製品の品質向上と洗浄油の長寿命化の効果があります。
また、セラポアはROの前処理としても使用頂いています。
セラポア濾過によりFI値を下げることができる為、RO膜の延命化に繋がります。

〈実例紹介〉

④活性炭を取り除きたい

納入先：飲料用水、化粧品、化学

〈フロー例〉

清涼飲料水向けの水からの異物と塩素除去のために活性炭濾過を行っています。
逆洗により繰り返しの使用が可能な為、ランニングコストを低く抑えることが可能です。
また、製品の脱色目的で原液に活性炭を混合させた後での濾過を行っています。
水平濾板型濾過機では、捕捉した活性炭の回収が容易です。

〈実例紹介〉

⑤結晶を回収したい

納入先：化学

〈フロー例〉

化学メーカーでは、反応物の濾過を行い、結晶物の回収目的で濾過を行うことがあります。
バッチ量に合わせて濾過面積を選択することが可能であり、単板型のHPFタイプでは、結晶物の回収を固形の状態で容易に行うことが可能です。

⑥有効成分を回収したい

納入先：化粧品

〈フロー例〉

化粧品の成分などの有効成分を回収する目的で濾過を行うことがあります。
回収量に合わせて収容ケーク量を選択することが可能であり、単板型のHPFタイプでは、有効成分の回収を固形の状態で容易に行うことが可能です。
